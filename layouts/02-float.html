02 · Float

The gray figure floats left and the paragraphs wrap around it.

Before flexbox and grid, floats were how the web did columns. A floated box is shifted to one side and removed from normal flow; the text that follows shortens its lines to run alongside it.

Keep reading and the lines keep wrapping. This figure is taller than all three paragraphs, so every line stays narrow — text only returns to full width once it passes the bottom of a float.

Floats were designed for exactly this — images in running text — which is why using them for whole page layouts always felt like a workaround.

Footer — clear: both makes this start below the float. Delete that one line and this footer slides up beside the figure.
